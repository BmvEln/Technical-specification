
| Уникальный код и название       | ВИ-1: Повторить слова с помощью карточек                                                                                                     |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Контекст использования          | Закрепление в памяти новых слов, чтобы не забыть их к следующему уроку                                                                       |
| Область действия                | Веб-приложение Chatty                                                                                                                        |
| Уровень                         | Цель пользователя                                                                                                                            |
| Основное действующее лицо       | Ученик                                                                                                                                       |
| Предусловие                     | - Ученик авторизован в Chatty<br>- Ученик находится на экране раздела карточек<br>- В карточках ученика есть хотя бы одно слово              |
| Гарантии успеха                 | - Результаты сохранены<br>- Статистика обновлена<br>- Ученик видел итоги сессии                                                              |
| Триггер                         | Ученик хочет повторить слова*                                                                                                                |
| Базовый сценарий                |                                                                                                                                              |
| 1                               | Ученик нажимает кнопку повторить слова                                                                                                       |
| 2                               | Система показывает карточку со словом (без перевода) с учетом текущего режима перевода                                                       |
| 3                               | Ученик вспоминает и нажимает на карточку                                                                                                     |
| 4                               | Система показывает перевод слова                                                                                                             |
| 5                               | Ученик отмечает, правильно или он вспомнил перевод                                                                                           |
| 6                               | Система сохраняет результат и показывает следующую карточку                                                                                  |
| 7                               | Шаги 2-6 повторяются, пока есть карточки                                                                                                     |
| 8                               | Система показывает итоги сессии                                                                                                              |
| Расширения                      |                                                                                                                                              |
| *а                              | Технический сбой на любом шаге: система показывает сообщение «Произошла ошибка при выполнении операции. Попробуйте повторить действие позже» |
| 3а                              | Ученик переключил режим перевода: система применяет новый режим к следующим карточкам                                                        |
| 5а                              | Ученик выбрал посмотреть статистику по карточке: система показывает её. После просмотра ученик возвращается к шагу 5                         |
| 5б                              | Ученик выбрал удалить карточку: система исключает её из сессии и списка карточек                                                             |
| 5в                              | Ученик удалил последнюю оставшуюся карточку: система переходит к шагу 8, где сообщает, что карточек не осталось                              |
| Изменения в технологии и данных | Карточки и статистика хранятся на сервере                                                                                                    |
*-  *Используется намерение в качестве триггера (на основе материала курса). В целом, триггером может быть как событие, намерение и бизнес-событие - что использовать зависит от команды, курса.

| Область действия                | Веб-приложение Chatty                                                                                                                        |
| Уровень                         | Цель пользователя                                                                                                                            |
| Основное действующее лицо       | Ученик                                                                                                                                       |

| Триггер                         | Ученик хочет добавить слова в карточки из словаря                                                                                            |
| Базовый сценарий                |                                                                                                                                              |
| 1                               | Ученик открывает свой словарь                                                                                                                |

| Расширения                      |                                                                                                                                              |
| *а                              | Технический сбой на любом шаге: система показывает сообщение «Произошла ошибка при выполнении операции. Попробуйте повторить действие позже» |
| 2а                              | Словарь пуст: система сообщает об этом                                                                                                       |
